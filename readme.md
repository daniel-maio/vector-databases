# Vector Databases

A collection of projects focused on **Vector Databases** and modern **RAG systems**.

This repository contains implementations of concepts such as **Retrieval-Augmented Generation (RAG)**, **Semantic Search**, **Embedding Models**, **Hybrid Search**, and document retrieval pipelines.

## Features

* Semantic Search
* Retrieval-Augmented Generation (RAG)
* Embedding generation
* Vector indexing
* Similarity search
* Hybrid search
* LLM integrations
* End-to-end retrieval pipelines

## Technologies

Depending on the project, you'll find tools and frameworks such as:

* LangChain / LlamaIndex
* FAISS
* ChromaDB
* Pinecone
* Milvus
* Qdrant
* Embedding models

## Purpose

The goal of this repository is to explore the ecosystem of vector databases through practical, reproducible projects ranging from simple semantic search applications to complete RAG pipelines.
